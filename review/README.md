# Extracted review data

`extracted_review_data.json` holds the values extracted from the 17 peer-reviewed studies (2024–2026) analysed in
Sections 3–4 of the paper: for each study, its hybrid and standalone models, whether baselines were tuned,
the six-item reporting checklist, and per-dataset error values as reported by the original authors (`ref` gives
the source). Values were transcribed from the published full texts; if you spot a transcription error,
please open an issue.
