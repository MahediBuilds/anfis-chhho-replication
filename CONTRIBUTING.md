# Contributing

Thanks for your interest! This repository accompanies a research paper, so the main goal is that anyone can
re-run, check and extend the experiments.

**Welcome contributions**
- Reproduction reports: if you re-ran the pipeline, open an issue with your OS, Python/NumPy versions and
  whether your `results/summary.json` matches ours. Mismatches are just as useful as matches.
- Bug reports and fixes, especially anything that would change a number in the paper.
- Extensions: new optimisers, new datasets, rolling-origin evaluation, other hybrid families.
  Please add them as new options rather than changing the defaults, so the paper's results stay reproducible.

**How to contribute**
1. Fork the repository and create a branch.
2. Keep changes small and focused; explain *why* in the pull-request description.
3. If your change affects results, say which numbers change and by how much.

Please be kind and constructive in issues and reviews. Disagreement about methods is welcome;
personal attacks are not.
